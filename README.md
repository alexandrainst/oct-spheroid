### Usage of .devcontainer

Steps that are required to use the .devcontainer within your projects for reproducable development environments.

1. Make sure you have the "Devcontainer" extension installed in your IDE.
2. Open the project folder in your IDE.
3. Click on the green button in the bottom left corner of your IDE and select "Open Folder in Container".

The first time this will take a while, as the container image needs to be built. After that, the container will be reused and you can start developing.
