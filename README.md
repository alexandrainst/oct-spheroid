## Installing / Getting started
In order to configure the environment you need to build an image based on the DockerFile. All the requirements should be included.

## Starting the script

All the functionality is included in the main.py file.

From there you can either train a 2D or 3D model. You can also evaluate either of the models.

First you select the splits, where you need to provide the path.

Then you can either train or evaluaate.

From training you need to provided training and validation dataloaders, model name, number of epochs, patience, learning rate. For training of the 2D multiview you can also select the number of classes that you want to included in your classification.
